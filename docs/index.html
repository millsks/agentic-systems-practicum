How this course works

1 · Read and run

Every lesson mixes explanation with runnable cells. Edit the code and press Ctrl/⌘+Enter. Real CPython runs in your browser.

2 · Watch the loop

The agent-loop visualizer steps through every request, tool call, and result so you can see how the message list grows.

3 · Practice

Graded exercises check your code with tests against a scripted model. Hints and solutions are there when you need them.

4 · Read traces

Professionals debug agents by reading transcripts. You will too: trace-reading and broken-agent exercises in every stage.

5 · Prove it

Each module ends with a quiz, flashcards, and a mini-project you build locally with Pixi.

6 · Build

Each level ends with a graded capstone: pixi run start c1, then pixi run grade c1.

flowchart LR
  O[0 · Orientation] --> S1[Stage 1 · Talking to a model] --> S2[Stage 2 · Tool use and the loop] --> C1[Capstone 1]
  C1 -.-> L2[Level 2 · Practitioner] -.-> L3[Level 3 · Production] -.-> L4[Level 4 · Professional]

Level 1 (Novice) is available now. Levels 2-4 (context and memory, workflow patterns, evaluation, safety, shipping, and multi-agent systems) are on the roadmap.

All local work uses Pixi. From the repository root: pixi install once, pixi run serve to open this site, pixi run projects to list capstones, pixi run start c1 to copy a starter into work/, and pixi run grade c1 to run its tests.

Level 1 takes about 25-30 hours including the capstone. You need Python through functions, classes, exceptions, and dictionaries; the Python Practicum covers all of it.
