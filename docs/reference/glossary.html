A

Adaptive thinking
The model decides for itself how much to reason before answering. It is the only thinking mode on Opus 5.5 ({"type": "adaptive"} or omitted); depth is steered with effort. M03 Limits, Effort & Stop Reasons
additionalProperties
A JSON Schema keyword; set to false, it forbids keys not listed in properties. Strict tools require it. M07 Tools as Contracts
Agent
A model running in a loop with tools: it decides which tool to call, your code runs it, and the result goes back until the model finishes the task. M00 How This Practicum Works
Agent loop
The while loop that sends a request, runs any requested tools, appends the results, and repeats until stop_reason is not tool_use or a budget runs out. M09 The Agent Loop
agentlab
The practicum's teaching library: a scripted mock of the Messages API plus helpers for transcripts, schema validation, and token estimates. M00 How This Practicum Works
API key
The secret that authenticates requests to the Claude API. It comes from the environment (ANTHROPIC_API_KEY or an ant auth login profile), never from code, notebooks, or commits. M00 How This Practicum Works
APIConnectionError
The request never reached the API (network failure or timeout). Retry with backoff. M10 Errors as Data
Assistant role
The role of messages the model wrote. You append the model's response.content as an assistant message to keep the history complete. M02 The Messages API

B

Backoff
Waiting longer between each retry of a failed call (for example 1 s, 2 s, 4 s) so a struggling service can recover. M10 Errors as Data
BadRequestError
HTTP 400: the request is malformed, for example an unanswered tool_use or a rejected parameter. Fix the request; retrying it unchanged fails again. M10 Errors as Data
Budget
A limit that ends a run: steps, tokens, cost, or wall-clock time. Every agent needs at least a step limit. M11 Stop Conditions & Budgets

C

Claude Agent SDK
A separate Anthropic product for building agents with a ready-made harness. Level 1 teaches the manual loop first so you know what such tools do for you. M09 The Agent Loop
Confirmation
A check your dispatcher makes before running a write tool, by asking a human or a policy. A declined write returns an is_error result. M12 Tool Design
Content block
One typed piece of a message's content: text, tool_use, or tool_result. A message's content is a string or a list of blocks. M02 The Messages API
Context window
The maximum number of tokens a model can read in one request, including the whole history and tool definitions. 1M tokens for current Claude models. M01 What an LLM Call Is
Cost budget
A dollar limit computed from usage and per-token prices; the run stops when it is exceeded. M11 Stop Conditions & Budgets
count_tokens
client.messages.count_tokens(...): returns how many input tokens a request would use, without generating anything. M01 What an LLM Call Is
Cursor
An opaque value a paginated tool returns as next_cursor; the model passes it back to get the next page. M12 Tool Design

D

Dispatcher
Your code that maps a tool_use block's name to a Python function, runs it with the block's input, and builds the tool_result. M08 One Tool Call by Hand

E

Effort
output_config={"effort": ...}: low, medium, high, xhigh, or max. Trades depth of reasoning against speed and cost; Opus 5.5 defaults to medium. M03 Limits, Effort & Stop Reasons
end_turn
The stop_reason when the model finished its answer normally. M03 Limits, Effort & Stop Reasons
Extraction
Turning unstructured text into structured data, such as fields from an email, usually with a JSON Schema. M05 Structured Output

F

Few-shot prompting
Including a few worked examples of input and desired output in the prompt so the model copies the pattern. M06 Prompting That Holds Up
format_transcript
al.format_transcript(messages): renders a conversation one block per line, the first thing to print when debugging a run. M00 How This Practicum Works

G

get_client
al.get_client(): returns a real anthropic.Anthropic() client when the package is installed; raises LiveModelUnavailableError in the browser. M00 How This Practicum Works
get_final_message
A streaming helper that consumes the rest of the stream and returns the complete Message. M04 Streaming

I

Idempotent
Safe to repeat: doing it twice has the same effect as once. set_done(id, True) is idempotent; toggle_done(id) is not. M12 Tool Design
Input and output tokens
Input tokens are what the request sends (history, system, tools); output tokens are what the model generates. Output tokens cost more. M01 What an LLM Call Is
input_json_delta
A stream event delta carrying a fragment of a tool call's input JSON, so tool input can be shown as it is generated. M04 Streaming
input_schema
The JSON Schema in a tool definition that describes the tool's arguments. Its top level is always {"type": "object"}. M07 Tools as Contracts
is_error
A tool_result flag. "is_error": True tells the model the tool failed; the content should say why and how to recover. M10 Errors as Data

J

JSON Schema
A standard vocabulary for describing the shape of JSON data (types, required keys, enums, limits). Used for tool inputs and structured output. M05 Structured Output

L

Latency
Time from sending a request to getting the answer. Driven mostly by output length, model size, and input size. M01 What an LLM Call Is
Loop detection
Stopping a run when the model repeats the same tool call with the same input, a sign it is stuck. M11 Stop Conditions & Budgets

M

max_tokens
The required cap on output tokens for one request. Reaching it stops generation with stop_reason="max_tokens" and cut-off content. M03 Limits, Effort & Stop Reasons
Message
One entry in messages with a role and content; also the response object the API returns. M02 The Messages API
Messages API
The Claude API endpoint for conversations: you send a model, a token limit, and a list of messages, and get back the next assistant message. M02 The Messages API
messages.parse
The SDK helper that requests structured output and validates it into a Pydantic model; the production path for typed results. M05 Structured Output
MockClient
agentlab's scripted stand-in for anthropic.Anthropic(). It validates requests like the API and answers from a script, offline and deterministically. M00 How This Practicum Works
MockScriptError
Raised when a MockClient script is wrong or used up. It signals a bug in the exercise, not in your agent. agentlab Reference
Model id
The string naming the model, such as claude-opus-5-5, claude-sonnet-5-5, or claude-haiku-5-5, with no date suffix. M02 The Messages API

N

Next-token prediction
How a language model generates text: it repeatedly predicts a likely next token given everything so far. M01 What an LLM Call Is

O

output_config
The request field for output settings: effort and format (structured output). Replaces the deprecated output_format. M03 Limits, Effort & Stop Reasons

P

Pagination
Returning a long list one page at a time, with a total and a next_cursor, so tool results stay small. M12 Tool Design
Parallel tool use
Several tool_use blocks in one response. Run them all and return every tool_result in one user message. M09 The Agent Loop
pause_turn
A stop_reason from server tools: the turn paused. Append the assistant turn and send the request again to continue. M03 Limits, Effort & Stop Reasons
Pixi
The package manager and task runner the course uses for Python, packages, and running code: pixi add, pixi run. M00 How This Practicum Works
Prefill
Ending messages with an assistant turn to start the model's answer for it. Rejected on current models. M03 Limits, Effort & Stop Reasons
Prompt injection
Untrusted text (a document, web page, or tool result) containing instructions that try to override yours. Keep instructions separate from data. M06 Prompting That Holds Up
Prompt regression test
A test that runs a prompt against fixed cases and checks the outputs, so prompt changes are reviewed like code changes. M06 Prompting That Holds Up

R

RateLimitError
HTTP 429: too many requests. Wait (honoring any retry-after hint) and retry. M10 Errors as Data
Read tool
A tool that only looks (search, read, list) and changes nothing. Safe to call by mistake or twice. M12 Tool Design
Refusal
A stop_reason meaning the model declined the request; stop_details gives a category and explanation. M03 Limits, Effort & Stop Reasons
Retry
Sending a failed request again. Right for 429, 5xx, and connection errors; wrong for 400s. The SDK retries some errors twice by default. M10 Errors as Data
Role
Who wrote a message: user or assistant. The first message is always user; the system prompt goes in the separate system field. M02 The Messages API
Run result
The structured report an agent run returns: answer, steps, tokens, cost, and the reason it stopped. M11 Stop Conditions & Budgets

S

Sampling parameters
temperature, top_p, and top_k. Rejected with a 400 on current models; steer with the prompt and effort instead. M03 Limits, Effort & Stop Reasons
Statelessness
The API remembers nothing between requests; you send the full history every time, and the history is a list you own. M02 The Messages API
stop_details
Extra information on a refusal: category and explanation. M03 Limits, Effort & Stop Reasons
stop_reason
Why generation stopped: end_turn, max_tokens, stop_sequence, tool_use, pause_turn, or refusal. Check it before reading content. M03 Limits, Effort & Stop Reasons
stop_sequences
Strings that end generation when the model produces them; the response then has stop_reason="stop_sequence". M03 Limits, Effort & Stop Reasons
Stream event
One server-sent event of a streamed response: message_start, content_block_start, content_block_delta, content_block_stop, message_delta, message_stop. M04 Streaming
Streaming
Receiving the response as it is generated rather than all at once, for faster first output and long responses. M04 Streaming
Strict tool
A tool with "strict": True, which guarantees the model's input matches the schema. Requires additionalProperties: false and required. M07 Tools as Contracts
Structured output
Responses guaranteed to match a JSON Schema, requested with output_config.format. M05 Structured Output
System prompt
The system parameter: instructions and context that frame the whole conversation, sent outside messages. M02 The Messages API

T

text_stream
A streaming helper that yields only the text fragments of a response as they arrive. M04 Streaming
Token
The unit models read and write: a word, part of a word, or punctuation. English averages about four characters per token. M01 What an LLM Call Is
Token budget
A cap on total tokens for a run, summed from each response's usage. M11 Stop Conditions & Budgets
Tokenization
Splitting text into tokens. Different models and languages tokenize differently, so count with count_tokens. M01 What an LLM Call Is
Tool
A capability you offer the model as a name, a description, and an input schema. The model asks for calls; your code runs them. M07 Tools as Contracts
Tool description
The prose in a tool definition that says what the tool does, when to use it, and what it returns. The model's main guide to choosing tools. M07 Tools as Contracts
Tool runner
The SDK's beta helper (client.beta.messages.tool_runner) that runs the agent loop for you. M09 The Agent Loop
tool_choice
Controls tool use: auto (default) or none. Forcing a call (any/tool) is rejected on Opus 5.5. M07 Tools as Contracts
tool_result
The block you send back in a user message with a tool's output, its tool_use_id, and optionally is_error. M08 One Tool Call by Hand
tool_use
The block the model sends to request a tool call: id, name, and parsed input. Comes with stop_reason="tool_use". M08 One Tool Call by Hand
tool_use_id
The field in a tool_result that must equal the id of the tool_use it answers. M08 One Tool Call by Hand
Transcript
The full sequence of messages and blocks in a run. Reading it is the main way to understand and debug an agent. M00 How This Practicum Works
Truncation
Cutting a long tool result to a size cap, with a visible note saying what was cut and how to get more. M12 Tool Design

U

Untrusted data
Text you did not write, such as user files, web pages, or tool results. Wrap it in tags and never treat it as instructions. M06 Prompting That Holds Up
Usage
The token counts on every response: input_tokens and output_tokens (plus cache counters). M02 The Messages API
User role
The role of messages you send: the human's turns and all tool_result blocks. M02 The Messages API

W

Wall-clock limit
A time limit on a whole run, measured with time.monotonic(). M11 Stop Conditions & Budgets
Write tool
A tool that changes something outside the conversation (create, update, delete, send). Gate it with confirmation and make it idempotent. M12 Tool Design

X

XML tags
Tags such as <document> that mark where inputs begin and end in a prompt, separating data from instructions. M06 Prompting That Holds Up
